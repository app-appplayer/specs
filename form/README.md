# Form — Specification

A schema-based document generation engine: fix a template, fill only the
content, and every output is a professionally structured document — résumés,
reports, invoices, contracts, business cards, exam sheets. Filled by an LLM,
knowledge, or a person; the structure never drifts. Built on the
[Model Context Protocol](https://modelcontextprotocol.io). One template model;
six render formats (PDF, HTML, DOCX, Markdown, UI DSL, and a pure-Dart PNG).
