# Gateway — Specification

The MakeMind Gateway Dispatch Protocol — how full [Model Context Protocol](https://modelcontextprotocol.io) traffic crosses a mediated relay: a tool-providing node dials out from behind NAT, consumers reach it through a hub, and the gateway layer at each endpoint carries requests, notifications, and the reverse (server-to-client) direction over opaque relay frames. One frame vocabulary; many bindings.
